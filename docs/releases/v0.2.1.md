# SilverHamu v0.2.1

This patch adds dependency inventories and vulnerability checks to SilverHamu's
release process. Each Windows/Linux service distribution, Windows Owner package
and Docker image is now accompanied by an SBOM that can be rescanned without
rebuilding the application. Database formats and the C ABI are unchanged.

## SBOMs and vulnerability checks

- Every archive has `<archive>.syft.json` and `<archive>.cdx.json` sidecars.
  Syft JSON preserves inventory metadata for Grype rescanning; CycloneDX JSON
  supports other SBOM consumers.
- `SHA256SUMS` covers all four archives and all eight SBOMs. Check downloaded
  files against this manifest before use.
- Release checks reject High and Critical findings, including findings without
  fixes. Dependency checks run on pull requests, main pushes and daily. Published
  inventories are rescanned daily and can also be rescanned manually by tag.
- Rust inventories include the release's Cargo.lock. This is a conservative
  dependency candidate list and can include optional or platform-specific
  dependencies that are not linked into a particular binary.

See [SBOM coverage and response steps](https://github.com/dhq-boiler/SilverHamu/blob/v0.2.1/docs/security-sbom.md)
for inventory limits, reports and remediation guidance. An empty findings list
does not guarantee that the software has no vulnerabilities.

## Downloads and setup

- `silverhamu-owner-v0.2.1-windows-x64.zip`: extract the entire archive and start
  `SilverHamu.Owner.exe`. Includes the .NET and Windows App SDK runtimes. Requires
  Windows x64, Windows 10 version 1809 or later. The application is unsigned.
- `silverhamu-v0.2.1-windows-x64.zip`: native library, authenticated TCP service,
  backup/restore utility and self-contained SQL host. Read the included `README.txt`.
- `silverhamu-v0.2.1-linux-x64.tar.gz`: Linux service, native library,
  backup/restore utility and self-contained SQL host. Built on Ubuntu 24.04;
  requires glibc 2.39 or later.
- `silverhamu-0.2.1-linux-amd64-docker.tar.gz`: load with
  `docker load -i silverhamu-0.2.1-linux-amd64-docker.tar.gz`.
  Image tag: `silverhamu:0.2.1`. Persist the complete `/data` volume and mount
  the token file read-only.

Back up databases before upgrading. Keep the database file, token files and
account/replication state together according to the
[backup guidance](https://github.com/dhq-boiler/SilverHamu/blob/v0.2.1/docs/backup.md).
Read the [service setup](https://github.com/dhq-boiler/SilverHamu/blob/v0.2.1/docs/service.md)
and [Owner instructions](https://github.com/dhq-boiler/SilverHamu/blob/v0.2.1/apps/SilverHamu.Owner/README.md)
before running the distribution.

Language clients remain separately versioned: Rust client 0.2.1 and the other
published clients 0.2.0 are unchanged and are not republished by this release.
